# Emotional Reasoning

***

### “Emotional Reasoning”

***

Menganggap sesuatu pasti benar hanya karena terasa benar.

#### Penjelasan

***

Perasaan itu nyata, tetapi perasaan bukan bukti. Emotional reasoning terjadi saat kita memperlakukan rasa sebagai fakta: "aku merasa begitu, berarti memang begitu."

Contohnya merasa diabaikan, lalu menyimpulkan bahwa orang lain sudah tidak peduli. Rasa diabaikannya mungkin benar adanya. Kesimpulan "tidak peduli" itu yang belum tentu.

{% hint style="info" %}
**Intinya:** perasaan memberi tahu apa yang kurasakan, bukan selalu apa yang sebenarnya terjadi.
{% endhint %}

#### For Example

***

{% tabs %}
{% tab title="A" %}
**Merasa diabaikan.** Pesan belum dibalas. Rasa: dicuekin. Kesimpulan: _"Dia sudah tidak peduli."_
{% endtab %}

{% tab title="B" %}
**Merasa gagal.** Satu kesalahan terjadi. Rasa: malu. Kesimpulan: _"Aku memang tidak berguna."_
{% endtab %}

{% tab title="C" %}
**Merasa takut.** Ada hal baru di depan. Rasa: cemas. Kesimpulan: _"Pasti akan buruk."_
{% endtab %}
{% endtabs %}

#### Cara memisahkan rasa dari kesimpulan

***

{% stepper %}
{% step %}
**Namai rasanya.** Ini kecewa, cemas, malu, atau lelah?
{% endstep %}

{% step %}
**Pisahkan dua kalimat.** "Aku merasa ..." adalah rasa. "Berarti ..." adalah kesimpulan, dan itu yang perlu diuji.
{% endstep %}

{% step %}
**Cari bukti dua arah.** Apa yang mendukung kesimpulanku, dan apa yang membantahnya?
{% endstep %}

{% step %}
**Bertanya sebelum menyimpulkan.** Tanya dengan tenang, bukan langsung menuduh.
{% endstep %}
{% endstepper %}

<details>

<summary>Apakah berarti perasaanku salah?</summary>

Tidak. Perasaan tetap valid sebagai sinyal. Yang diuji hanya kesimpulan yang kita tarik darinya.

</details>

<details>

<summary>Bagaimana kalau perasaanku ternyata benar?</summary>

Bisa saja. Menguji kesimpulan bukan berarti menolaknya, hanya memastikan ia punya dasar sebelum menjadi tindakan.

</details>

{% hint style="warning" %}
**Yang kupegang:** perasaan itu data, bukan putusan.
{% endhint %}
