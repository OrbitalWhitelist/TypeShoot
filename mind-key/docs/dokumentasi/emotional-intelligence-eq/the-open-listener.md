# The Open Listener

## The Open Listener

***

### “The Open Listener”

***

Catatan tentang sifat mendengarkan dengan terbuka: memahami orang lain tanpa harus menyetujui semua yang ia katakan.

{% hint style="info" %}
**Intinya:** mendengarkan bukan berarti setuju. Mendengarkan berarti memberi ruang.
{% endhint %}

### Apa itu The Open Listener?

***

Ini sifat orang yang mendengarkan untuk memahami, bukan untuk menyiapkan jawaban. Ia mengenali apa yang dirasakan lawan bicara, menahan diri dari menyimpulkan terlalu cepat, dan tetap punya pendapat sendiri.

Banyak orang berhenti bercerita bukan karena tidak percaya pada pendengarnya, tetapi karena takut langsung disanggah atau dinilai. Pendengar yang baik memberi ruang dulu, dan menyimpan kesimpulannya untuk nanti.

### Empati dan persetujuan itu berbeda

{% tabs %}
{% tab title="Empati" %}
Melihat apa yang dirasakan dan dibutuhkan seseorang. Contoh kalimat: "Masuk akal kamu merasa begitu."
{% endtab %}

{% tab title="Persetujuan" %}
Penilaian atas keputusan atau tindakannya. Contoh kalimat: "Aku setuju atau tidak setuju dengan pilihanmu."
{% endtab %}

{% tab title="Kenapa dipisah?" %}
Karena dua hal itu bisa berjalan sendiri-sendiri. Aku bisa memahami perasaan seseorang tanpa membenarkan semua pilihannya. Dengan memisahkannya, orang merasa aman bercerita, dan aku tetap jujur pada pendapatku.
{% endtab %}
{% endtabs %}

### Cara mendengarkan yang kupakai

{% stepper %}
{% step %}
**Dengarkan sampai selesai.** Jangan memotong atau menyiapkan bantahan di tengah.
{% endstep %}

{% step %}
**Validasi singkat.** Satu kalimat seperti "masuk akal kamu mikir begitu."
{% endstep %}

{% step %}
**Satu pertanyaan terbuka.** Misalnya "dari kapan kamu merasa begitu?"
{% endstep %}

{% step %}
**Minta izin sebelum memberi masukan.** "Mau masukan, atau cukup didengarkan?"
{% endstep %}

{% step %}
**Jaga ceritanya.** Cerita itu milik orangnya, bukan bahan obrolan lain.
{% endstep %}
{% endstepper %}

<details>

<summary>Bagaimana kalau aku tidak setuju?</summary>

Aku tetap boleh tidak setuju. Bedanya, aku menyampaikannya setelah mendengarkan, dengan izin, dan tanpa merendahkan. Contoh: "Boleh aku kasih sudut pandang lain? Kalau nggak mau, nggak apa-apa."

</details>

<details>

<summary>Hal yang kuhindari saat mendengarkan</summary>

Langsung menyimpulkan, membandingkan ("yang lain lebih parah"), menyepelekan ("santai aja"), dan membocorkan cerita ke orang lain.

</details>

{% hint style="success" %}
**Yang kupegang:** memahami dulu, menilai belakangan.
{% endhint %}
